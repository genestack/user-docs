# Contribute data

The Contribute tab covers creating studies, importing data, curating and versioning metadata, working with templates, and sharing studies through the ODM user interface. For API-based contribution workflows, see the [ODM API > Contribute](../odm-api/contribute/index.md) section.

## What you can contribute

ODM supports importing studies, sample metadata, libraries, preparations, experimental data (in formats such as GCT and VCF), cell metadata, and attached files such as reports, images, and publications. For definitions of these entities and how they relate to one another, see the [Data model](../overview/data-model/index.md).

!!! info
    Data import and editing permissions are restricted to users who are part of the **Curator** group within ODM.

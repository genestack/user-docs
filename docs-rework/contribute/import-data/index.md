# Import Data

This section covers importing data into a study through the ODM user interface. Each page corresponds to one type of data you can add.

## What you can import

<div class="grid cards gs-section-cards" markdown>

- __[Import sample metadata](import-sample-metadata.md)__

    ---

    Upload a TSV file of sample attributes.

- __[Import libraries and preparations](import-libraries-and-preparations.md)__

    ---

    Add library and preparation entities and link them to samples.

- __[Import experimental data](import-experimental-data.md)__

    ---

    Upload signal data in GCT, VCF, HDF5, FACS, or TSV format.

- __[Attach files](attach-files.md)__

    ---

    Attach supplementary reports, images, and publications.

</div>

For API-based import workflows, see [ODM API > Contribute > Import data](../../odm-api/contribute/import-data/about-the-import-workflow.md).

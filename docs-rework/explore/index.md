# Explore data

The Explore tab covers finding, viewing, visualising, and exporting data through the ODM web interface. For API-based data access, see the [ODM API > Explore](../odm-api/explore/index.md) section.

## What's in this tab

<div class="grid cards gs-section-cards" markdown>

- __[Search and filter studies](search-and-filter-studies.md)__

    ---

    Find studies by keyword, metadata, or data class.

- __[View study metadata](view-study-metadata.md)__

    ---

    Read study, sample, and data metadata.

- __[Visualise sample data](visualise-sample-data.md)__

    ---

    Create attribute plots within a study.

- __[Export data](export-data.md)__

    ---

    Download a study's data and metadata.

- __[Bookmark studies](bookmark-studies.md)__

    ---

    Save studies for quick access.

</div>

To orient yourself to the Study Browser interface before diving in, see [Navigating the UI: Study Browser](../overview/navigating-the-ui/study-browser.md).

# ODM SDK

ODM SDK is a Python package providing command-line scripts and a Python client library for working with ODM. It complements the REST API by offering pre-built workflows for common tasks: data import, study sharing, user creation, template management, and dictionary management.

## When to use the SDK

Use the SDK for one-time scripted imports, automated workflows, and integration with existing Python tooling. For interactive API exploration and request-by-request development, use the Swagger UI instead. See [Swagger orientation](../../odm-api/getting-started/swagger-orientation.md).

# How to configure facets

This guide explains how to customise which metadata fields appear as search facets in the Study Browser filter panel.

## Prerequisites

You must have the **Configure facets** permission. See [Permissions](../overview/access-control/permissions.md).

Changes you make here apply to all users on the ODM instance, not just your own view.

## Steps

1. Open the Study Browser.
2. Click the cog icon at the bottom of the filter panel.
3. To add a facet, click **New Facet** and type the exact name of the metadata field you want to add. Field names are case-sensitive.
4. To reorder facets, drag the icon next to a facet name to its new position.
5. To delete a facet, click the bin icon next to it.
6. Click **Save** to apply your changes.

> The panel will not save if any facet field is empty or if there is a duplicate facet name.

Facets that you configure here appear in the filter panel of the Study Browser for all users when they search for studies. For guidance on using the filter panel as a researcher, see [Search and filter studies](../explore/search-and-filter-studies.md). For an overview of the Study Browser interface, see [Study Browser](../overview/navigating-the-ui/study-browser.md).

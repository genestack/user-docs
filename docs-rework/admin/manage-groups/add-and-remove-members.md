# How to add and remove group members

This guide explains how to add users to a group and remove them in ODM.

## Prerequisites

To add or remove members from a group where you are the Group Admin, no additional permission is required beyond your admin role in that group.

To add or remove members from any group across the instance, you need the **Manage groups** permission. See [Permissions](../../overview/access-control/permissions.md).

## Add members

1. Click the three-line menu at the top left of the Dashboard.
2. Select **Groups**.
3. Select the group you want to manage.
4. Click **+ New members**.
5. In the window that appears, select users from the list or use the search bar to find specific users.
6. Click **Add member** to confirm.

The group immediately reflects the new members.

## Remove members

1. Navigate to the group from which you want to remove a user.
2. Use the search bar or scroll through the member list to find the user.
3. Click the three-dot menu ( ⋮ ) next to the member's name.
4. Select **Remove member**.

> **Note:** only users with the role of Group member can be removed directly. If you need to remove a Group admin, you must first promote another member to Group admin; every group must have at least one admin. See [Manage group admins and roles](manage-group-admins-and-roles.md) for how to change roles.

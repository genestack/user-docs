# Contribute via API

Contributing data through the API means getting your studies and their data into ODM and wired together, all without leaving your scripts or pipeline. This section walks you through importing your data, linking it up, and transforming it, at whatever level of automation your work calls for. For the same operations through the ODM user interface, see [Contribute data](../../contribute/index.md). If you would rather learn by doing, start with the [Getting started as a Data Contributor](../getting-started/getting-started-contributor.md) tutorial.

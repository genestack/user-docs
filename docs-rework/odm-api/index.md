# ODM API

The ODM API is a RESTful API that provides programmatic access to your data and to platform administration through Swagger-documented endpoints. This tab is self-contained. It covers everything from authentication and navigating the Swagger UI to exploring, contributing, and administering data via the API, along with the cross-cutting reference material that ties it together.

For the equivalent operations through the ODM user interface, see the [Explore data](../explore/index.md), [Contribute data](../contribute/index.md), and [Admin](../admin/index.md) tabs.

# Cell metadata reference

Cell metadata is uploaded to ODM as a TSV file. Required attributes are described below. Any column not in the canonical list is stored as a custom attribute with string data type.

## Stored attributes

| Attribute name | Stored as type | Description | Required |
|---|---|---|---|
| cellID | string | Unique cell identifier generated by ODM (composite key of `groupAccession` + `barcode`) | Yes |
| barcode | string | Raw cell barcode. Must be unique within the group. | Yes |
| batch | string | Sample/batch origin | Yes |
| cellType | string | Annotated cell type | |
| cluster | string | Clustering labels | |
| nCounts | integer | Total UMI count (Unique Molecular Identifier) | |
| percentMito | float | Percentage mitochondrial gene expression | |
| umap | float | Dimensionality reduction results (UMAP). Up to 3 values stored. | |
| pca | float | Dimensionality reduction results (PCA). Up to 100 values stored. | |
| tsne | float | Dimensionality reduction results (t-SNE). Up to 3 values stored. | |

## Validation rules

**Fail conditions (import rejected):**

- Missing required attributes (`barcode` or `batch`).
- Duplicate barcode values within a Cell Group.
- Blank values in required attributes.

**Warnings (values ignored):**

- Invalid data type for a recognised attribute (for example, a non-numeric value in `nCounts`).

## Custom attributes

Any column not listed above is stored as a custom string attribute. There is no limit on the number of custom attributes.

When using the HDF5 transformation pipeline, additional attribute names from tools such as Seurat, Scanpy, or Cell Ranger are automatically mapped to the canonical names in this table before import. For the full set of recognised alternative names (for example, `n_counts` → `nCounts`, `sample_id` → `batch`), see [Attribute mapping reference](../contribute/transformations/single-cell/attribute-mapping-reference.md).

# Navigating the UI

The Study Browser, Metadata Editor, and Template Editor are ODM's shared workspaces. You'll encounter them whether you're searching for a dataset, curating sample metadata, or configuring validation rules. This section introduces each one so you can move through the task areas without stopping to orient yourself.

<div class="grid cards gs-task-cards" markdown>

- __[Study Browser](study-browser.md)__

    ---

    The main interface for finding, filtering, and opening studies.

- __[Metadata Editor](metadata-editor.md)__

    ---

    Where you view and edit a study's metadata: samples, libraries, preparations, data, and attachments.

- __[Template Editor](template-editor.md)__

    ---

    Where you create and manage metadata templates that govern field validation.

</div>

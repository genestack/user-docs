# Supported data formats

ODM supports several data formats for import. Each format has its own page describing the structure, accepted variants, and how ODM uses the file.

<div class="grid cards gs-section-cards" markdown>

- __[TSV (Tabular data)](tsv.md)__

    ---

    Upload and manage tabular data in TSV format. Works with samples, libraries, preparations, expression data, and more.

- __[GCT (Gene Expression)](gct.md)__

    ---

    Upload and work with GCT (Gene Cluster Text) files for microarray and RNA-seq expression datasets.

- __[VCF (Variants)](vcf.md)__

    ---

    Upload and work with VCF (Variant Call Format) files to search, filter, and analyse genetic variants.

- __[HDF5](hdf5.md)__

    ---

    Upload and store HDF5 files as attachments with file structure parsing and search by contents.

- __[FACS (Flow Cytometry)](facs.md)__

    ---

    Upload and work with FACS (Fluorescence-Activated Cell Sorting) files for flow cytometry data.

- __[Attached files](attached-files.md)__

    ---

    Attach any file type to a study. Attached files are stored and retrievable but not indexed for content search.

</div>

For the full list of Data Class values used when importing files, see [Data classes reference](../data-model/data-classes-reference.md).

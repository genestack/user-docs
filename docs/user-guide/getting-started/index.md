# Getting Started

Welcome to the Open Data Manager. Choose the page that matches your role to find the tasks and guides most relevant to you.

## Roles

- **[Data Consumer](consumer.md)** — for users who browse, search, visualize, and export data without creating or modifying studies.
- **[Data Contributor](contributor.md)** — for users who create studies, import data, curate metadata, and share results with others.
- **[Administrator](admin.md)** — for users who manage users, groups, and permissions across the ODM instance.

Not sure which role you have? See [Roles & Permissions](../reference/roles-permissions.md).

# Export data from a study

In addition to browsing, exploring, and visualising studies, you can also export full datasets.

## Exporting a Study

Export data functionality is available in both the Study Browser and Metadata Editor.

1. **Study Browser:**
   In the Study Browser window, access the **Export data** button from the three-dot menu to the left of the study name.

   ![export-data-study-browser.gif](../../doc-odm-user-guide/doc-odm-user-guide/gifs/export-data-study-browser.gif)
   <figcaption>Export the data by clicking on the <strong>Export data</strong> option in Study Browser</figcaption>

2. **Metadata Editor:**
   In your study window, click the **Export** button. The Export button can be accessed from the right side of the window or by clicking on the study title to reveal a dropdown menu with the export option. The menu can also be accessed by clicking the three dots next to the Export option on the right side of the screen.

   ![export-study-from-me](../../doc-odm-user-guide/doc-odm-user-guide/gifs/export-study-from-me.gif)
   <figcaption>Export the data by clicking on the <strong>Export data</strong> option in Metadata Editor</figcaption>

Clicking **Export data** opens a new window where all files associated with the study are compressed.

* Once the files are compressed, the download button becomes active and the files can be downloaded to your local computer.
* The link is pre-authenticated, so anyone with the link can download the study and associated data.
* Previously generated export links are listed at the bottom of the screen. These are archive versions reflecting the data at the time the link was generated, not necessarily the latest version.

![2CompressingData.png](../../doc-odm-user-guide/doc-odm-user-guide/images/2CompressingData.png)
<figcaption>Files will be compressed, and once ready, the folder can be downloaded to the user's local computer.</figcaption>

## Understanding the Downloaded Contents

* The downloaded folder contains all linked and attached files related to the specific study.
* A text file named **file_descriptions** (in plain text format) is included, summarising the information of the downloaded files.

![3_Contents.png](../../doc-odm-user-guide/doc-odm-user-guide/images/3_Contents.png)
<figcaption>Downloaded files. The downloaded folder contains all the data and metadata associated with the study. In addition, a plain text file called <strong>file_descriptions</strong> is automatically created and contains detailed information about the data that has been downloaded</figcaption>

## Exporting a Specific Dataset

You can export a specific dataset of interest, but this functionality is only available from the **Data** tab. Navigate to the Data tab containing the desired analysis and click the **Download file** button. Note that it is not currently possible to export only sample metadata or study metadata separately.

The dataset, along with its corresponding metadata and description, will be compressed into an archive and made available via a download link.

![4OtherDataSets.png](../../doc-odm-user-guide/doc-odm-user-guide/images/4OtherDataSets.png)
<figcaption>Download specific datasets by selecting them and clicking on <strong>Download file</strong></figcaption>

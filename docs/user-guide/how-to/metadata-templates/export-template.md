# Export a template

**Role:** Contributor.

You can export a template as a JSON file containing all of its configuration details.

## Steps

1. Open the **Template Editor** from the Dashboard or the shortcut dock.
2. In the list of available templates, click the name of the template you want to export.
3. Select **Export** from the drop-down menu.

   ![image](../../doc-odm-user-guide/doc-odm-user-guide/images/Template_dropdown.png)

4. A JSON file containing the template information will be downloaded to your local computer.

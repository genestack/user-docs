# Open Data Manager user guide

Welcome to the **Open Data Manager (ODM) User Guide**.

ODM is a data management platform for life sciences that lets teams import, curate, search, and share multi-omics study data through a web interface and a REST API.

## Who are you?

Choose your role to find the right starting point:

- **[Data Consumer](getting-started/consumer.md)** — browse, search, filter, visualise, and export data. Cannot create or modify studies.
- **[Data Contributor](getting-started/contributor.md)** — create studies, import data, curate metadata, manage templates, and share studies.
- **[Administrator](getting-started/admin.md)** — manage users and groups, assign permissions, and govern access.

Not sure which role you have? See [Roles & Permissions](reference/roles-permissions.md).

# Tutorials

Tutorials are learning-oriented. Each tutorial guides you through a complete, meaningful task so you understand how ODM works — not just how to click buttons.

If you are new to ODM, start with [Your First Session](your-first-session.md).

---

## General

| Tutorial | Description | Audience |
|---|---|---|
| [Your First Session](your-first-session.md) | Log in, navigate the Dashboard, find a study in the Study Browser, and open its metadata in the Metadata Editor. | All roles |
| [Curate a Study](curate-a-study.md) | Take a newly imported study from raw to validated state by correcting metadata fields and using bulk replacement. | Contributor |

# Documentation
Follow the Diátaxis framework (https://diataxis.fr) for writing docs. Structure all documentation into four distinct types:
- **Tutorials** — learning-oriented, guide the user through a task to teach concepts
- **How-to guides** — task-oriented, step-by-step instructions to solve a specific problem
- **Reference** — information-oriented, factual descriptions of the system (APIs, config options)
- **Explanation** — understanding-oriented, background and context that deepens comprehension
